## 💡 Идея

Хочется заниматься английским, спортом, чтением, рисованием — но времени вечно
не хватает, а попытки «впихнуть всё сразу» заканчиваются выгоранием.

**Anti-Overload** решает эту проблему:

1. спрашивает, чем ты хочешь заниматься и как устроен твой день;
2. учитывает твои обязательные дела — работу, учёбу, тренировки;
3. сам расставляет цели по свободным окнам недели;
4. оставляет паузы между занятиями, чтобы ты не перегорал.

| 🔒 **Безопасный вывод** | Весь пользовательский ввод экранируется (защита от XSS) |

## 🧩 Как работает планировщик

Текущий алгоритм — это базовая версия, которую в будущем заменит и дополнит ИИ.

```text
Цели ──► сортировка по приоритету и частоте
              │
              ▼
   для каждой цели и каждого повтора:
     • выбрать наименее загруженный день
     • искать свободное окно с шагом 30 минут
     • учесть предпочтительное время (утро / день / вечер)
     • оставить 15 минут отдыха до и после занятия
              │
              ▼
        План на неделю 🎉
```

**Правила на данный момент:**

- ⏰ окно бодрствования по умолчанию — **08:00–22:00**;
- 🌅 утро — 08:00–12:00, 🌞 день — 12:00–18:00, 🌙 вечер — 18:00–22:00;
- 📈 приоритет: высокий → средний → низкий;
- 🔁 одна цель не ставится дважды в один день;
- 🧘 между занятиями и обязательными делами — буфер в 15 минут.

## 🚀 Быстрый старт

### 1. Клонируй репозиторий

```bash
git clone <ссылка-на-твой-репозиторий>
cd <папка-проекта>
```

### 2. Создай виртуальное окружение *(рекомендуется)*

```bash
python -m venv venv

# Linux / macOS
source venv/bin/activate

# Windows
venv\Scripts\activate
```

### 3. Установи зависимости

```bash
pip install fastapi uvicorn python-multipart
```

### 4. Запусти приложение

```bash
uvicorn main:app --reload
```

### 5. Открой в браузере

👉 **http://127.0.0.1:8000**

> 💡 Файл базы данных `database.db` создаётся автоматически при первом запуске.

## 🗺 Страницы приложения

| Адрес | Что делает |
|---|---|
| `/` | Анкета → цели и обязательные дела |
| `/plan` | Сохранённый план на неделю |
| `/generate` *(POST)* | Составить или пересоставить план |
| `/finish` *(POST)* | Сводка всех введённых данных |
| `/restart` *(POST)* | Сбросить все данные и начать заново |
